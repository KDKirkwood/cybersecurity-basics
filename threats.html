Common Threats

Attackers use tricks, harmful software and weak spots in systems. Here are the main types to know about.

Social Engineering

Social engineering means tricking a person instead of breaking into a computer. The attacker pretends to be someone trustworthy so the victim gives up a password or money.

Phishing

A phishing email looks like it came from a bank or a school but the link goes to a fake website. Spear phishing is the same idea, only the message is written for one specific person. Check the sender address and never click a link you were not expecting.

Email Scams

Fake messages that ask you to reply with private details, or that fill up inboxes with junk.

Advance Fee Fraud

The victim is promised a large amount of money but has to pay a small fee first. The money never arrives.

Rogue Antivirus

Pop-ups that claim your computer is infected and tell you to download a "fix". The download is the real problem.

Malware

Malware is short for malicious software. It is any program made to damage a system or steal from it.

Spreading Types

  • Virus - attaches itself to a file and spreads when the file is opened
  • Worm - copies itself across a network on its own
  • Trojan - looks like a normal program but hides something harmful

Spying Types

  • Spyware - watches what you do
  • Keylogger - records what you type
  • Adware - shows unwanted ads

Damaging Types

  • Ransomware - locks your files until you pay
  • Rootkit - hides other malware on a system
  • Botnet - a group of infected computers controlled by one attacker

Intrusions

An intrusion is when someone gets into a system without permission. This is often done by guessing passwords or by using a bug the company does not know about yet.

Interception

Attackers can watch traffic on open Wi-Fi and read data that is not encrypted.

Brute Force

A program tries thousands of password guesses until one works. Short passwords fall quickly.

Zero Day

An attack that uses a flaw nobody has fixed yet, so there is no patch available.
