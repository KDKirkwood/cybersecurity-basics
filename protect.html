Staying Protected

You cannot stop every attack, but a few good habits and the right tools make you a much harder target.

Verifying Identity

Authentication is how a system checks that you are really you, most often with a username and password.

Strong Passwords

Long passwords are harder to crack than short ones. Password entropy is a measure of how random and hard to guess a password is.

Two-Factor Authentication

You prove who you are with two things, like a password and a code sent to your phone. A stolen password alone is not enough.

Password Managers

A password manager stores a different password for every site, so you only remember one.

Protecting Data

Encryption

Encryption scrambles data so that anyone who intercepts it cannot read it. The receiver uses a key to turn it back into readable text, which is called decryption. Websites use TLS (the newer version of SSL) and that is what shows the padlock in the browser. Admins use SSH to log in to another computer safely.

Defending Your Devices

Antivirus

Antivirus software scans files and compares them to known malware. If something is found it gets quarantined. Keep it updated so it knows about new threats.

Firewalls and IDS

A firewall blocks traffic that should not get in. An intrusion detection system (IDS) watches the network and warns when something looks wrong.

Good Habits

  • Install updates quickly
  • Do not click unknown links
  • Avoid unknown USB drives
  • Back up important files

More Help
